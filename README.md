# Bonderium

## Установка

1. Скачайте [ZIP-архив последней версии в **Releases**](https://github.com/finiksmacom11-rgb/Bonderium/releases/latest)
   и распакуйте его.
2. Дважды щёлкните `install.bat`. Терминал, Python и компилятор для установки
   не нужны; установщик скачает текущую версию приложения.
3. Запускайте Bonderium через ярлык на рабочем столе.

Окно отображает перспективную 3D-сцену с бесконечной XY-сеткой и осями X, Y и Z.
Мировые координаты и радиусы молекул задаются в единицах сетки. WASD или
стрелки плавно перемещают камеру по горизонтальной плоскости, Q/E — вверх и
вниз, вращайте вид правой кнопкой мыши и приближайте колёсиком. Средняя кнопка
мыши перемещает точку обзора; Home возвращает камеру в исходное положение.
После размещения перетаскивайте сферу левой кнопкой мыши, в том числе вдоль
мировой оси Y.

Кнопка **OPT** в верхней панели открывает настройки графики: режим
**Performance** уменьшает детализацию сфер и плотность сетки, **Balanced**
сохраняет обычную детализацию, а **High quality** повышает детализацию сфер и
сглаживание линий. Там же можно скрыть сетку. Полноэкранный режим включается
через это меню или клавишей `F11`; повторное нажатие возвращает исходный размер
и расположение окна.

Создавайте молекулы-сферы: нажмите **+ Molecule** или `C`, наведите указатель
на XY-плоскость и щёлкните, чтобы разместить сферу; `Esc` отменяет режим
размещения. Shift+колесо мыши меняет высоту Z размещаемых сфер. Молекулы хранят
3D-положение и радиус.

Нажмите кнопку выбора атома в верхней панели: откроется прямоугольная панель
в стиле клавиатуры с буквенными клавишами **O**, **H** и **Ю**. Выберите букву
и затем размещайте атомы обычным способом. Кислород отображается красным,
водород — светлым цветом, а Юреум — бирюзово-темным. Для кислорода заданы
масса 15,999, заряд −0,834, радиус 0,60 и параметры
Леннарда—Джонса σ = 0,75, ε = 0,15; для водорода — масса 1,008, заряд
+0,417, радиус 0,32, σ = 0,25, ε = 0,02; для Юреума — масса 1,000, заряд
0, радиус 0,42, σ = 0,75, ε = 0,10. Энергетические параметры используют
безразмерные единицы движка. Чтобы собрать H₂O, сначала добавьте один атом
кислорода, затем добавьте два атома водорода. Водород без кислорода создать
нельзя, но после добавления первых двух атомов водорода дальнейшее создание
не блокируется. Для создания связей включите режим клавишей `B` и выберите
два атома мышью; угол между связями рассчитывается по их текущему расположению.

### Экспериментальная молекулярная динамика

Симуляция запускается кнопкой **START EXP** или клавишей `Space`. Для выбранной
молекулы клавиши `[` и `]` меняют заряд с шагом 0,5; `Shift` вместе с этими
клавишами меняет целевую температуру термостата с шагом 0,05. Нажмите `B` и выберите
две молекулы, чтобы соединить их гармонической связью; при соединении
автоматически добавляется гармонический угол между связями с общим атомом.
`Esc` отменяет активный режим размещения или создания связи.
Чтобы придать выбранной молекуле импульс, нажмите `F`, затем протяните мышью
от неё в нужную сторону и отпустите кнопку. Стрелка показывает направление,
а длина перетаскивания задаёт силу импульса. Это работает и во время запущенного
эксперимента; `Esc` отменяет прицеливание.

Движок реализует парный потенциал Леннарда—Джонса, прямое кулоновское
взаимодействие или его приближение Barnes—Hut, гармонические связи и углы,
гравитацию, мягкие или отражающие границы, термостаты Андерсена и Берендсена,
а также затухание скоростей. `T` циклически переключает термостаты, `I` меняет
интегратор между velocity Verlet и kick-drift-kick, `O` выбирает кулоновский
решатель, `P` переключает режим границ, `G` включает/выключает гравитацию.
По умолчанию сцена не ограничена стенами, а гравитация и термостат выключены.

Физика пока использует безразмерные приведённые единицы (`kB = 1`); температура
и энергия не откалиброваны под конкретный химический элемент. Это классическая
динамика частиц, а не квантовая химия или моделирование химических реакций.
Кулоновские силы по умолчанию вычисляются прямым суммированием; Barnes—Hut —
приближённый метод, включаемый для систем от 64 частиц.

Кандидаты пар для короткодействующего взаимодействия кэшируются в списке
Верле, построенном по пространственным ячейкам. Список перестраивается при
смещении частицы более чем на половину skin-расстояния, изменении состава
системы или параметров cutoff/skin. Смешанные параметры Леннарда—Джонса
кэшируются для каждой пары. Проверки движка запускаются командой
`ctest --test-dir build`.

Нижняя панель показывает FPS, число молекул, шаги симуляции в секунду,
приведённую температуру, потенциальную энергию, заряд выбранной молекулы,
время кадра, скорость камеры и время работы. Ping показывает `N/A`, поскольку
приложение пока не подключается к серверу. Для отрисовки используется
системный OpenGL; интерфейс оформлен в тёмном стиле.

При каждом запуске приложение в фоновом режиме проверяет наличие новой версии.
Проверка не задерживает открытие окна; сетевые запросы ограничены короткими
тайм-аутами. Если доступна новая версия, Bonderium предложит её установить.
Предлагаются как стабильные, так и бета-версии; бета явно помечается в запросе.
При отказе приложение запоминает только выбранный тег, поэтому он больше не
показывается, а более новые бета- и стабильные версии по-прежнему предлагаются.
После подтверждения приложение закроется, обновится и запустится снова.

## Выпуск обновления

GitHub Actions автоматически собирает Windows x64 и публикует ZIP-архив в
**Releases**, когда в Git отправлен тег формата `vX.Y.Z`, например `v0.2.0`.
Бета-версии выпускаются отдельными предварительными релизами с тегом
`vX.Y.Z-beta.N`, например `v0.2.0-beta.1`.

## Разработка

Для сборки из исходного кода нужны VS Code с расширениями Microsoft C/C++ и
CMake Tools, CMake и компилятор LLVM-MinGW (`clang++` или `g++` и
`mingw32-make`). Добавьте CMake и папку `bin` LLVM-MinGW в переменную `PATH`.

Запустить локальную сборку и приложение можно командой:

```powershell
python run.py
```

Локальные сборки не проверяют обновления. Проверка включена в релизные сборки.
Исходный код окна находится в `src/main.cpp`, проверка обновлений — в
`src/updater.cpp`. Создаваемая CMake папка `build/` не добавляется в Git.
