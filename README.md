# Bonderium

## Установка

1. Скачайте [ZIP-архив последней версии в **Releases**](https://github.com/finiksmacom11-rgb/Bonderium/releases/latest)
   и распакуйте его.
2. Дважды щёлкните `install.bat`. Терминал, Python и компилятор для установки
   не нужны; установщик скачает текущую версию приложения.
3. Запускайте Bonderium через ярлык на рабочем столе.

Окно отображает перспективную 3D-сцену с бесконечной XY-сеткой и осями X, Y и Z.
Мировые координаты и радиусы молекул задаются в единицах сетки. WASD или
стрелки плавно перемещают камеру по горизонтальной плоскости, Q/E — вверх и
вниз, вращайте вид правой кнопкой мыши и приближайте колёсиком. Средняя кнопка
мыши перемещает точку обзора; Home возвращает камеру в исходное положение.
После размещения перетаскивайте сферу левой кнопкой мыши, в том числе вдоль
мировой оси Y.

Создавайте молекулы-сферы: нажмите **+ Molecule** или `C`, наведите указатель
на XY-плоскость и щёлкните, чтобы разместить сферу; `Esc` отменяет режим
размещения. Shift+колесо мыши меняет высоту Z размещаемых сфер. Молекулы хранят
3D-положение и радиус.

Панель внизу отображает FPS, число молекул, время кадра, скорость камеры и
время работы. Шаги симуляции показывают `OFF`, пока не добавлена физика
молекулярных взаимодействий; ping показывает `N/A`, поскольку приложение
пока не подключается к серверу. Для отрисовки используется системный OpenGL.
Интерфейс оформлен в тёмном стиле.

При каждом запуске приложение в фоновом режиме проверяет наличие новой версии.
Проверка не задерживает открытие окна; сетевые запросы ограничены короткими
тайм-аутами. Если доступна новая версия, Bonderium предложит её установить.
После подтверждения приложение закроется, обновится и запустится снова.

## Выпуск обновления

GitHub Actions автоматически собирает Windows x64 и публикует ZIP-архив в
**Releases**, когда в Git отправлен тег формата `vX.Y.Z`, например `v0.2.0`.
Бета-версии выпускаются отдельными предварительными релизами с тегом
`vX.Y.Z-beta.N`, например `v0.2.0-beta.1`.

## Разработка

Для сборки из исходного кода нужны VS Code с расширениями Microsoft C/C++ и
CMake Tools, CMake и компилятор LLVM-MinGW (`clang++` или `g++` и
`mingw32-make`). Добавьте CMake и папку `bin` LLVM-MinGW в переменную `PATH`.

Запустить локальную сборку и приложение можно командой:

```powershell
python run.py
```

Локальные сборки не проверяют обновления. Проверка включена в релизные сборки.
Исходный код окна находится в `src/main.cpp`, проверка обновлений — в
`src/updater.cpp`. Создаваемая CMake папка `build/` не добавляется в Git.
